# Image binaries for the 6502 Second Processor version of Elite

This folder contains the image binaries from the original sources for the 6502 Second Processor version of Elite on Ian Bell's personal website.

* [P.DATE2P.bin](P.DATE2P.bin) is an unused image that was used to datestamp the title screen during development

* [P.DIALS2P.bin](P.DIALS2P.bin) is the original game's colour dashboard image

* [P.DIALSW.bin](P.DIALSW.bin) is the P.DIALS2P dashboard image but converted to white

* [P.DIALSH1.bin](P.DIALSH1.bin) to [P.DIALSH4.bin](P.DIALSH4.bin) contain the anaglyph 3D scanner ellipses at four different levels of parallax

* [P.DIALS.bin](P.DIALS.bin) is the P.DIALS2P dashboard image but with a blank scanner section, so the 2D dashboard dials can be merged with the anaglyph 3D scanner ellipse images in P.DIALSH1 to P.DIALSH4

* [P.DIALSH1W.bin](P.DIALSH1W.bin) to [P.DIALSH4W.bin](P.DIALSH4W.bin) contain the four different anaglyph 3D scanner ellipses, merged with the white dashboard dials to give the final anaglyph dashboard images

* [Z.(C)ASOFT.bin](Z.(C)ASOFT.bin) is the "(c) ACORNSOFT 1984" image for the bottom of the title screen

* [Z.(C)ASOFTW.bin](Z.(C)ASOFTW.bin) is the "(c) ACORNSOFT 1984" image for the bottom of the title screen, converted to white

* [Z.ACSOFT.bin](Z.ACSOFT.bin) is the "ACORNSOFT" image for the very top of the title screen

* [Z.ACSOFTW.bin](Z.ACSOFTW.bin) is the "ACORNSOFT" image for the very top of the title screen, converted to white

* [Z.ELITE.bin](Z.ELITE.bin) is the "ELITE" image for the title screen

* [Z.ELITEW.bin](Z.ELITEW.bin) is the "ELITE" image for the title screen, converted to white
